Cloak v0.3.0 (Beta) introduces 3-tier Security Profiles, Saved Project Profiles, full 5-rail Connected Apps (Claude Code, OpenCode, Goose + Privacy Shield + Spend Guardrails), loopback local server discovery, native Local Voice, Smart Private Router, and Darkbloom Mac Guardrails.

What's new in v0.3.0:
- 3-Tier Security Profiles (Settings → General): Choose Local Only + Downloads (hard-blocks all cloud modes, cloud wallets, Tor/VM, and network serving), Anon Private Cloud (zkAPI only with Tor, Cover Traffic, and Local Prompt Rewriting locked ON), or Private Cloud AI (all modes and rails).
- Connected Apps (CloakDoor) Expansion: Native Anthropic Messages API (/v1/messages, count_tokens, SSE streaming, tool calling, Claude aliases) plus OpenAI Chat Completions across all 5 rails (Local $0, NEAR TEE, Venice Base, Boundless Tempo, zkAPI Anon), 1-click Test Connection, and quickstart presets for Claude Code, OpenCode, and Goose.
- Privacy Shield & Spend Guardrails: Deterministic pre-send Secret Tripwire (scans messages, tool definitions, and tool results before paying), reversible in-memory entity aliases (never rehydrating tool arguments), and token-bounded local Spend Guardrails with real model pricing and zkAPI request-cap checks.
- Saved Project Profiles (free in beta): Keep each client or repository cleanly isolated across approved Local folders, Privacy Shield private terms, preferred route, and Connected Apps model overrides with 1-click switching in Chat's sidebar.
- Faster Local AI & Local Voice: RAM-only paged KV prefix caching and Fast/Balanced/Deep reasoning effort in vmlx-swift, strictly loopback-only (127.0.0.1) auto-discovery for Splash, TensorFold, mlx-serve, LM Studio, Ollama, and Darkbloom Local, plus on-device macOS 26 Local Voice dictation & speech synthesis.
- Private Cloud UX & Darkbloom Guardrails: Smart Private Router (Fast / Coding / Deep Reasoning), Stripe Link & Apple Pay self-custodial wallet funding links, and Darkbloom Mac Guardrails (auto-pause on battery, high thermal pressure, or Quiet Hours) with live RAM budget & Earn-to-Spend display.
- Security & Reliability Fixes: Direct Token Inference fails closed when prompt rewriting is enabled without a local rewriter, Redacted Diagnostic Reports scrub full lines before truncation under a live 5-second timeout, and zkAPI auto-withdraw retries cleanly if a wallet refresh overlaps the gas fee check.

Beta & Wallet Security Notice: Cloak v0.3 is beta software and has not yet been independently audited. Keep wallet balances small, back up or withdraw funds before wiping or switching Macs (keys never sync to iCloud), and note the 30-day protocol limit on untouched zkAPI deposits. Read the full Wallet Security & Recovery guide at regents.sh/docs/cloak/wallets.
