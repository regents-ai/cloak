Cloak now has four kinds of chat: V, Token Inference, NEAR Private AI and Local Llama. The Modes button beside the message box says what each one does and how it is paid for.

V is new. Each message is reworded on this Mac and sent through Tor, and each request is paid with a new key, from a deposit of ETH. You make the deposit in the Wallet window: send a little ETH to the address it shows, type an amount in dollars, and Review shows the fee and the total in ETH and in dollars before anything is sent. The Wallet shows the day the deposit expires; withdraw before then. V's wallet is new, so deposit only a little.

Token Inference is the new name for Anon. One wallet on this Mac pays for every request in USDC.e on Tempo. The Boundless and Tempo marks in the Wallet window say how the two are used.

Local Llama chats work while Cloak is paused, and Settings lets you choose which model answers them.

The model is its own download now, 5.69 GB. Download Model shows its size and where it comes from, and nothing is fetched until you press Download.

NEAR Private AI answers show how many tokens NEAR counted for them.

This is an early test build for invited testers. Things may break or change from one build to the next.
